- [x] Bug.33 — decklist round-trip mangled any name starting with `X `. `parse_decklist("X 0")` gives name `"X 0"`, but `decklist/format.py` re-serializes as `f"{qty} {name}"` -> `"1 X 0"`, which parsed back as name `"0"`: the detached `X` was eaten as a quantity multiplier. format -> parse is a production round-trip (`/decks/*` responses hand back re-serialized lists), so this silently corrupted decklists.
